Shared node for Logos apps

Fertile ground for
local-first apps.

Loam is an Android app you install once; your Logos apps share its node. One connection to the Logos network for every app on your phone, with no server in between.

On the desktop, Basecamp apps get the same thing from the loam_core module, which they install automatically.

Install Loam How it works

Screens

What you see on the phone.

Ten apps, one node, and you decide who uses it.

Without Loam, every Logos app on your phone runs its own node: its own connections, its own discovery, its own battery drain. Loam runs one node in its own process and lets every app share it.

Apps keep their data and their encryption to themselves. They seal each event before handing it to Loam, so Loam just carries ciphertext between your devices and the people you share with.

One node for every app

A single foreground service keeps one connection to the Logos network (Logos Delivery) for the whole phone. Apps bind to it instead of starting their own.

You approve each app

The first time an app wants the node, Loam shows “Allow an app to use Loam?”. Approval is tied to the app's package and signing key, so a re-signed copy has to ask again. You can revoke it any time.

Cache while an app is closed

Loam keeps listening for an app after you close it and holds its (still sealed) messages. When you reopen the app it picks them up straight away instead of re-syncing. On by default, switchable per app.

Bluetooth mesh experimental

When the internet drops, nearby phones running Loam can pass the same sealed messages to each other over Bluetooth, then go back to the network when it returns. Android only for now.

Identity and signing

Every event your apps write is signed. On the desktop, loam_core holds your keys and signs for the apps, so they never touch a private key. On Android the same identity code still runs inside each app and is moving into Loam. Keycard support is experimental.

Works without Loam too

Loam is recommended, not required. If it isn't installed, each app falls back to running its own node and still syncs. You only lose the sharing, the cache and the Bluetooth mesh.

How it works

Three layers of substrate.

Dig down from an app and this is what holds it up: the node it talks to, the engine that makes every device agree, and the transport that reaches the next device.

Topsoil01 · node
Loam xyz.vpavlin.loam · loam_core

The shared node. On Android it is the Loam app: one node in a foreground service, shared by every approved app, which also runs the experimental Bluetooth mesh. On the desktop the loam_core Basecamp module does the same job for Basecamp apps.
Subsoil02 · convergence
loam-sync

The agreement engine inside each app. An event-log CRDT with HLC ordering and range-based set reconciliation: every device folds the same events into the same state, in any arrival order, without losing a write.
Bedrock03 · reach
loam-transport

The client library apps build on. It talks to the Loam app when it is installed and falls back to an embedded node when it isn't. Two bearers: Logos Delivery, and the experimental Bluetooth mesh. A message that arrives over both is counted once.
01

Offline by default

No server is in the critical path. Each app keeps its own history on your device and works alone; it syncs whenever another device is reachable.

02

Room-scale mesh experimental

On Android, when the Logos network is out of reach, Loam switches on its Bluetooth mesh so phones in the same room can keep syncing, then returns to the network when it's back.

03

Convergent, not coordinated

Every write is an event folded by a CRDT. Two people editing the same thing offline both keep their change, and every device ends up with the same state.

04

Only ciphertext crosses the transport

Apps encrypt end to end before anything leaves them. Loam, relays and store nodes see sealed bytes plus routing metadata (topic, size, timing), never the content. Loam can't read any app's traffic, and apps can't read each other's.

After you install

Let the first app take root.

  1. Open Loam once. It starts the node and keeps it running in the background (you'll see its notification). Allow notifications so it can ask you about apps. The Logos network card turns green when it has peers.
  2. Open one of your apps. Loam posts “Allow an app to use Loam?”. Tap it and choose Allow. The app now uses the shared node; until you approve, it gets nothing from it.
  3. Check the approved apps list. Each app has Cache while closed (on by default) with a count of waiting messages, and a Revoke button.
  4. Optional: pick a node mode. Edge is lighter on battery and data; Core also relays for the network and suits a phone on Wi-Fi and power. Switching restarts Loam.
  5. Optional: try the Bluetooth mesh. It switches on by itself when the network drops; use Force on to test it with the internet still up. Grant the Bluetooth permission when asked. Experimental.

Status & limitations

What's solid, and what's still growing.

WorksThe shared node on Android, per-app approval, and the offline cache. The cache lives in memory, so it is lost if Loam itself restarts; apps then catch up over the network as usual.
WorksBasecamp 0.2.x with loam_core, pulled in by each app. Basecamp 0.3 support is coming.
ExperimentalBluetooth mesh, Android only. Desktop Bluetooth doesn't work yet.
ExperimentalKeycard signing. Not verified end to end yet.
ComingMessage budget (RLN). The Logos network is adding spam protection that gives each node a limited message rate, shared by all apps on it. Loam will manage that budget for your apps.
ComingThe desktop loam_ui panel, and identity moving from each Android app into Loam itself.
NoteAndroid builds are arm64 only. There is no public hub; if you want an always-on peer, run your own.

For operators

Optional node telemetry

Loam can record node diagnostics while offline and send them, encrypted, to a telemetry topic once it's back online. It is off by default: you set a shared secret and switch it on in the app. To collect it, run logos-hub with a profile that loads loam_core and point it at the exporter script from loam-transport (tools/loam-telemetry-exporter.mjs). It serves Prometheus metrics for Grafana.

logos-hub telemetry <profile> --secret <shared> --exporter loam-transport/tools/loam-telemetry-exporter.mjs --port 9109

You can also set TELEMETRY_SECRET and LOAM_TELEMETRY_EXPORTER instead of the flags.
